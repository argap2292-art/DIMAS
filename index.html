Integrasi Google Sheets & Apps Script

Cara menghubungkan laporan salat SDN 1 Candi ke Google Spreadsheet guru.

Status Integrasi Saat Ini:

Variabel GOOGLE_SCRIPT_URL berada di baris pertama script. Laporan otomatis tersimpan di memori lokal peramban (localStorage) dan dikirim ke Google Sheets jika URL aktif.

Langkah 3 Menit Menghubungkan Google Spreadsheet:

  1. Buka Google Sheets baru, beri judul "Rekap DIMAS SDN 1 Candi Ponorogo".
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Hapus kode bawaan, lalu tempelkan kode berikut:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Waktu Kirim", "Sekolah", "Tanggal Salat", "Nama Siswa", "Kelas", 
        "Jenis Kelamin", "Status Haiz", "Subuh", "Zuhur", 
        "Asar", "Magrib", "Isya", "Total Poin", "Catatan"
      ]);
    }
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      new Date(), "SDN 1 Candi", data.tanggal, data.nama, data.kelas,
      data.gender, data.isHaiz ? "Haiz" : "-",
      data.subuh, data.zuhur, data.asar, data.magrib, data.isya,
      data.totalPoin, data.catatan || ""
    ]);
    return ContentService.createTextOutput(
      JSON.stringify({ status: "success" })
    ).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(
      JSON.stringify({ status: "error", message: err.toString() })
    ).setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik tombol Deploy (Terapkan) → New Deployment.
  2. Pilih jenis Web App. Set Who has access ke "Anyone" (Siapa saja).
  3. Salin Web App URL, lalu tempelkan ke variabel GOOGLE_SCRIPT_URL.
